# 周期笔记台(journal-desk)

把「日记」从孤零零的今天,扩成一条**可前后走的时间轴**:日 / 周 / 月 / 季 / 年五种周期笔记
各有自己的路径格式与模板,前后一格随手跳,外加一张「哪天写了」的月历。

宿主内置只有一条 `amadeus-daily-note`(今天的日记)和一个「日记文件夹」设置 —— 没有周记月记、
没有前一天后一天、没有回看。本插件补的就是这一段。

---

## 用法

### 命令面板(六条)

| 命令 | 做什么 |
|---|---|
| **周期笔记台:打开** | 打开月历视图 |
| **周期笔记台:今天** | 去今天的日记(不存在就按模板建一份) |
| **周期笔记台:上一篇** | **按当前打开的那篇的周期**往前一格 |
| **周期笔记台:下一篇** | 同上,往后一格 |
| **周期笔记台:本周** | 去本周的周记 |
| **周期笔记台:本月** | 去本月的月记 |

**「上一篇 / 下一篇」的判据**:正开着 `Journal/2026-08-20.md` → 到 `Journal/2026-08-19.md`;
正开着 `Journal/周/2026-W34.md` → 到 `Journal/周/2026-W33.md`。跳的是**当前这篇的同类前一格**。
当前打开的不是周期笔记(或没开笔记)时,回落成「昨天 / 明天」。

**「本周 / 本月」恒相对今天**,不跟随当前打开的笔记 —— 只有「上一篇 / 下一篇」跟随。这条不对称是故意的:
前者是「去做本周小结」,后者是「在时间轴上走一步」。

### 月历视图

- 周一起始(与 ISO 周定义一致),恒 6 行 42 格,翻月时高度不跳。
- **有日记的日子**:日号下面一个圆点。点它 → 打开那篇,**一个字节都不写**。
- **空白日子**:点它 → 按模板建当天并打开。未来日期也允许建(写明天的计划是合法用法)。
- **非本月的补格**:点它只**切换月份**,不建任何文件(防误建)。
- 右上角「本周 / 本月 / 本季 / 本年」四个按钮恒相对今天,与命令面板同义。
- 顶部一行显示今天的日记路径预览(只显示「日」那一条)。

### 状态栏

右下角一条:写了显示「✓ 今天」,没写显示「✎ 今天没写」,悬停看目标路径,点一下就去写。
跨零点会自己翻篇(一个一次性 `setTimeout`,不是轮询;`setInterval` 全程零调用)。

> 显示态可以**略微陈旧**(它只看「当前打开的是不是今天的日记」和已枚举到的笔记清单,不为了显示单独去读盘)。
> 但**点击那一刻**会重新走完整的存在性探测 —— 显示「没写」而其实写了,点下去也只会打开,不会覆盖。

## 设置(10 条,插件详情页)

每种周期两条:一条**路径格式**、一条**模板路径**。

| 周期 | 路径格式(默认) | 模板(默认) |
|---|---|---|
| 日 | `Journal/{{date:YYYY-MM-DD}}` | 空 |
| 周 | `Journal/周/{{date:YYYY}}-W{{week}}` | 空 |
| 月 | `Journal/月/{{date:YYYY-MM}}` | 空 |
| 季 | `Journal/季/{{date:YYYY}}-Q{{quarter}}` | 空 |
| 年 | `Journal/年/{{date:YYYY}}` | 空 |

### 路径格式的变量(只有三个)

| 变量 | 值 |
|---|---|
| `{{date:FMT}}` | FMT 认 `YYYY` `YY` `MM` `M` `DD` `D` `HH` `mm` `ss`,**其余字符原样保留**(`{{date:YYYY年MM月}}` → `2026年08月`) |
| `{{week}}` | ISO 周号,两位补零(`01`..`53`) |
| `{{quarter}}` | `1`..`4`,不补零 |

- **不用写 `.md`**,插件自动补;你自己写了也不会重复补。
- 文件夹写在格式里(`Journal/月/…`),不另设「文件夹」设置。
- 首尾的 `/` 和重复的 `//` 会被归一掉。

### 模板

值是一条**笔记库内的 `.md` 路径**(如 `Templates/daily.md`)。

- **只在建文件那一刻读一次并做变量替换**,之后这篇笔记与模板再无关系(改模板不会回灌已有日记,
  也没有「重新套用模板」)。
- 模板正文里除了上面三个变量,还能用 `{{title}}`(= 目标文件名去掉 `.md`)。
- **留空** → 新笔记只有一行标题(`# 2026-08-21`),不提示。
- **填了但读不到** → 一样用一行标题兜底,但会弹一条 warning 告诉你模板没生效(不会静默)。

## 数据存哪

**周期笔记就是你自己笔记库里的普通 Markdown 笔记**,路径完全由上面五条格式决定(默认 `Journal/…`)。
它们可以被 `[[双链]]` 引用、被全局搜索命中、被你随手改名搬家 —— 和你手写的任何一篇笔记没有区别。

### ⚠️ 本插件不使用「工作文件夹」

插件详情页上那条宿主自动挂的「工作文件夹」设置对本插件**无效**,改它不会有任何效果。

这是刻意的:周期笔记**不是插件产物,是用户的日记本身**。把日记塞进「某个插件的工作文件夹」,
等于宣称这些笔记归插件所有 —— 卸载插件时用户会犹豫,搬家时路径会怪,双链引用也会指向一个插件名的目录。
代价是路径合法性不再由宿主统一兜底,所以插件自己做了完整校验(见下)。

### 也没有任何隐藏缓存 / sidecar

「哪天写了」是每次从 `listPages()` 的**路径反解**现算的,不落任何 `.journal-desk-*.json`。
缓存它只会引入一份会与真相不符的副本,而宿主的枚举本来就带 single-flight + 1.5s 短缓存。

唯一的例外是纯内存的一笔:刚建好的那天会被记下来直到宿主的枚举追上它(1.5s 缓存窗口),
免得你刚写完日记回到日历却看不到那个点。这笔记录不落盘,关掉 App 就没了。

## 它对你的文件做什么、不做什么

**唯一的写入动作**是:对一条**经三态探测确认「明确不存在」**的路径,做一次 `writeFile`,内容是模板
(或一行标题)。除此之外它对你的文件只有一个动作 —— **打开**。

三条硬纪律:

1. **读失败 ≠ 文件不存在。** 探测目标路径时区分三态:成功 / 明确不存在 / **读失败**。读失败(库正在切换、
   权限、IPC 断)一律**中止并报一条常驻错误,绝不写**。把读失败折叠成「还没有数据」的下一步,
   就是写一份只有 `# 2026-08-21` 的新日记,盖掉你已经写了一整天的那篇。
2. **同名绝不覆写。** 目标笔记已经存在 = 这正是你要去的地方 → 直接打开。没有「另存新版」,
   没有「把模板追加到末尾」,没有覆写路径。
3. **活动页保护。** 目标路径恰好就是你**当前正开着**的那篇时,最外层直接判定「已存在」,连 `readFile` 都不发
   (那份路径外的内容可能有你刚敲进去还没保存的字)。

另外:

- **路径合法性自己校验**,在发出任何 IPC 之前。拒绝:空串 / 绝对路径 / `..` / `.` / 空段 / `\` /
  控制字符 / `\ : * ? " < > |` / 不以 `.md` 结尾。
  (宿主的 `readFile` 对「文件缺失」和「路径越界」都返回 `null` —— 这个二义性必须在插件这层消掉,
  否则「越界」会被当成「不存在」然后走到建立分支。)
- **写后读回自校验**:写完再读一次。读不回来 = 硬失败并报错;读回来但与写入的不逐字节相同
  (宿主可能规范化了换行)= 软警告,仍算建立成功。
- **串行写队列**:狂点状态栏 / 日历格子时,并发的建立请求排队执行 —— 同一篇只会被建一次。

## 范围说明:明确不做什么

1. **不做事件日历。** 宿主内置已经有日历 + ICS —— 那张日历回答的是「**这天有什么事**」(多维表行、日程、
   订阅进来的 ICS)。**本插件的月历只回答一个问题:「这天有没有日记」。** 它不读日程、不读多维表、
   不读 ICS,格子上除了一个「写了」的点什么都不画。要看安排请用内置日历,两者互不替代也互不同步。
2. **不做提醒 / 推送 / 定时任务。** 插件跑在渲染层,App 一关它就不存在了 —— 承诺不了「晚上 10 点提醒你写日记」。
   唯一的定时器是一个跨午夜刷新状态栏的 `setTimeout`,只为让「今天写了没」在零点自己翻篇,不发任何通知。
3. **不做把已有笔记批量搬进日记结构。** 不重命名、不移动、不改写你任何一篇已存在的笔记。
   本插件对已存在文件的**唯一**动作是「打开它」。
4. **不覆写、不合并、不续写。** 目标周期笔记只要已经存在,就直接打开,一个字节都不写。没有「另存新版」,
   也没有「把模板追加到已有日记末尾」。
5. **模板只在建文件那一刻套一次。** 之后改模板不会回灌已建好的日记;也不提供「重新套用模板」。
6. **周数只有 ISO-8601 一种。** 周一起始,含 1 月 4 日的那周为第 1 周;`{{date:YYYY}}` 在周记里给的是
   **ISO 周年**(所以 `2025-12-29` 那一周的文件叫 `2026-W01` —— 否则它会和 2025 年 1 月那一周撞同一个文件)。
   v1 **没有**「周日起始 / 美式周数」选项。
   推论:**周记文件名里别混用 `{{date:MM}}`**,跨年周会出现 `2026` + `12` 这种正确但反直觉的组合。
7. **`上一篇` / `下一篇` 是「上一格 / 下一格」,不是「上一篇写过的」。** 目标不存在就按模板建一份。
   想跳到上一篇**真的写过的**,用日历视图找有点的日子。
8. **`本周` / `本月` 恒相对今天**,不跟随当前打开的笔记 —— 只有 `上一篇` / `下一篇` 跟随。
9. **不往「工作文件夹」写任何东西。** 周期笔记是你自己的笔记,路径完全由五条设置决定(默认 `Journal/…`)。
   插件详情页上那条宿主自动挂的「工作文件夹」设置对本插件**无效**。
   插件也**不存任何隐藏 sidecar / 缓存文件** ——「哪天写了」是每次从笔记路径现算的。
10. **不注册斜杠项、不碰笔记编辑器。** 本插件不往任何已打开的笔记里插入内容,没有 `/` 菜单项,
    也不注册编辑器扩展(`registerEditorExtension`)。
11. **不做成就、不做统计报表、不做连续打卡(streak)。**
12. **路径格式的变量只有三个**:`{{date:FMT}}` / `{{week}}` / `{{quarter}}`;FMT 只认
    `YYYY YY MM M DD D HH mm ss`,**没有转义机制**(想让文件名里出现字面上的 `MM` 做不到),
    也没有星期名(`ddd`)—— 那会随语言变,落盘就不一致了。
    `{{date:YY}}` 反解时一律当 `20xx`。文件名里带时间(`HH`/`mm`/`ss`)的格式**合法但会关掉日历标记**
    (一天多篇,「这天写了没」就不成立了),日历底部会说明原因。
    路径格式里**一个变量都没有**(常量路径)也是合法的 —— 所有笔记指向同一个文件,日历同样关掉标记并说明。
13. **命令面板 / 设置页 / 视图标签的标题在切语言后要重启才跟上。** 宿主的贡献点标题是注册时的单字符串,
    没有运行时重解析(已知缺口)。视图**内部**的文案切语言立刻就变。
14. **不做多库 / 跨库汇总。** 只管当前打开的这个笔记库。

## 中英双语

- 视图内的一切文案跟随宿主语言(设置里切中英),**切语言时视图不重挂也会立刻变**,
  月份游标也不会被重置。
- **已知缺口(宿主侧)**:命令面板标题、设置项标题、视图标签页标题是**注册时的单字符串**,
  宿主没有运行时重解析 —— 这几处要**重启后**才跟上语言切换。视图**内部**的文案切了立刻就变。
  这是宿主的已知缺口,插件不做「语言变了就重注册」的绕法(那会打断已打开的视图与在飞的写队列)。
- **落盘的一切不随语言变**:五条路径格式的默认值、兜底标题,全部钉死中文常量。
  否则英文界面下会建出 `Journal/Weekly/…`、中文界面下建出 `Journal/周/…`,同一个库里冒出两套日记结构,
  而且切一次语言你的「上一篇」就再也找不着了。

## 旧宿主兼容

07-18 之后的 `ctx` 面在旧宿主上可能缺席,全部可选链降级,`setup` 绝不抛错:

| 缺席的 API | 表现 |
|---|---|
| `ctx.registerView` / `ctx.openView` | 不注册视图;「打开」命令改为提示「当前宿主不支持插件视图」 |
| `ctx.registerStatusItem` | 没有状态栏项,其余照常 |
| `ctx.notify` | 回落 `ctx.app.notify`(没有 level 分级) |
| `ctx.getLocale` / `ctx.subscribeLocale` | 回退中文,不订阅语言变化 |
| `ctx.activity` | 不埋点 |
| `ctx.app.listPages` | 日历不画点、底部说明枚举不可用;建 / 开照常(它们不依赖枚举) |
| `ctx.app.subscribePage` | 状态栏只在命令执行后 / 午夜 / 视图操作后刷新 |
| `ctx.app.loadPage` | 回落 `ctx.app.openFile`(只在路径确定存在时调用) |

## 自检

```bash
cd forsion-plugin-journal
node check.mjs
```

宿主同款 `new Function('ctx', src)(mockCtx)` + DOM 垫片 + 冻钟 + 内存 vault + 假定时器。
覆盖:贡献点齐全、disposer 收干净、**核心纯函数向量在 UTC / Asia-Shanghai / Europe-London /
America-New_York 四个时区下逐条一致**(含两个 DST 日、跨年周、53 周年)、路径往返(`resolvePath` →
反解 → 同一个 anchor)、XSS、旧宿主降级、双语词表两侧键集合相等、zh→en→zh 逐字往返、
v4 载体零接触、活动页写保护三档、串行写队列、读回自校验软硬两档、模板三态、
`上一篇/下一篇`跟随活动页、非法路径零 IPC、枚举缺席降级、午夜定时器。
